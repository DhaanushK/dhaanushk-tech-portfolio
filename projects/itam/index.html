AT A GLANCE

From inventory to operational signals.

The project models hardware and software records, calculates lifecycle and licence indicators, then presents the results in modular Python reports and a four-page Power BI dashboard. It is structured as a maintainable analytics engine rather than a one-off workbook.

01 / QUESTION

What needs attention?

How can an organization understand which hardware is nearing end of life, where software licences are expired or over-assigned, and what financial exposure is associated with renewals?

The analysis brings together asset status, purchase value, useful life, warranty, licence seats, and renewal dates so that operational and financial risks can be reviewed together.

02 / BUILD

Model, calculate, explain.

Python asset classes represent hardware and software licences. A factory creates the right object for each inventory record; managers and analytics modules handle lifecycle, filtering, and calculations. Reporting and visualization remain separate so the same data can support summaries, charts, and dashboard outputs.

MySQL scripts organize the records relationally and support joins, aggregation, views, and audit review. The Power BI report connects to a remote semantic model and uses shared department and location filters across its pages.

03 / FINDINGS

Signals in the sample.

With the project’s fixed reference date of 25 August 2026, the sample inventory showed a material software renewal and hardware lifecycle review need.

73expired licences, representing ₹5.25M in renewal exposure
23licences with assigned seats above purchased seats
95hardware assets flagged as end-of-life candidates

The four dashboard pages cover executive overview, hardware lifecycle, software compliance, and financial/audit analysis.

04 / ENGINEERING

Choices and limits.

The project keeps asset types and analytical responsibilities in separate modules, which makes the calculations easier to extend and report independently. It combines purchase and depreciation values with warranty and lifecycle indicators, and distinguishes licence capacity from assignment.

The inventory is a sample dataset, not live organizational data. The reported findings are tied to the stated reference date and should not be read as current business exposure.
