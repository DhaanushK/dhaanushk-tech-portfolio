CASE STUDY 01 · PREDICTIVE MODELING

Wine Oracle:
Quality Prediction with Neural Alchemy

A hybrid MC-CNN and MLP classifier estimates wine quality from 11 physicochemical measurements. The project combines preprocessing, model training, and a sample-input prediction experience.

Try a prediction ↓ Explore the code ↗ Read the publication ↗
ROLECo-author · Co-Developer · Model development DATA14,852 rows in the bundled red and white datasets INPUTS11 physicochemical features MODELMC-CNN + MLP

AT A GLANCE

Estimate a quality class from lab measurements.

Wine Oracle accepts red or white wine measurements and returns the model's predicted quality class with its top-class probability. The demo follows the preprocessing and inference steps from the project repository.

The paper reports 87.6% accuracy for red wine and 90.0% for white wine. In the latest repository run, the combined MC-CNN and MLP model scored 87.41% on red wine and 90.58% on white wine. Local scores can vary slightly because the CNN initialization is not seeded.

01 / APPROACH

Two model paths, one prediction.

The MC-CNN processes two channels formed from the scaled measurements. In parallel, an MLP estimates class probabilities. The combined model receives both outputs and predicts a wine quality class. The browser predictor applies the saved transforms, feature engineering, and scaler before either model runs.

INPUT11 physicochemical measurements and red or white wine selection
PREPROCESSINGWine-specific raw-value transform, engineered alcohol-sulphate interaction, and saved standard scaler
OUTPUTPredicted class and probability assigned to that class
02 / INTERPRETATION

A model estimate, not a tasting.

The probability shown is the model's score for its top predicted class. It is not a calibrated measure of real-world certainty. The higher or lower label is a project-defined grouping using a predicted class cutoff of 6.

This demo estimates the dataset's quality label from lab measurements. It does not assess contamination, spoilage, safety, preference, or commercial value.
