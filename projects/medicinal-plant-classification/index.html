AT A GLANCE

Two visual branches, one prediction.

The model processes each image through a pretrained Vision Transformer and a CNN branch, then fuses their class scores. The recorded dataset run contains 5,995 images: 4,076 for training, 720 for validation, and 1,199 for testing. The training workflow includes a stratified validation split, image augmentation, class-weighted loss, early stopping, and a held-out test evaluation.

01 / PIPELINE

Prepare, train, evaluate.

Images are converted to RGB, resized and normalized using the checkpoint’s saved preprocessing settings. The app loads the trained weights and returns the three highest-scoring class predictions with their model confidence values.

02 / INTERPRETATION

Scores are estimates.

The confidence shown is the model’s score for a predicted class, not a guarantee that the identification is correct. Results depend on the image and on the classes represented during training.

This is an educational classifier only. It does not identify whether a plant is safe to consume or use medicinally, and it is not a substitute for expert identification.
